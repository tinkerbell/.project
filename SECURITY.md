# Security Policy

## Reporting Security Issues

The Tinkerbell maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/tinkerbell/tinkerbell/security/advisories/new) form.

For more details, see the [Tinkerbell security policy](https://github.com/tinkerbell/tinkerbell/blob/main/SECURITY.md).
